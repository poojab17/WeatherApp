#  Weather App

A simple weather application built using **HTML, CSS, and JavaScript**.

### Features

* Search weather by city
* Displays temperature, humidity, wind speed, and weather conditions
* Uses real-time data from the **OpenWeather API**

### Tech Used

* HTML
* CSS
* JavaScript
* OpenWeather API
* Fetch API

### What I Learned

This project helped me learn **API integration, API documentation, Fetch, async/await, JSON responses, and DOM manipulation**.
